# CoffeeBites – Sales & Business Performance Analysis

## Project Overview
CoffeeBites is a specialty coffee shop business analysis project covering six months of operations, from May to October 2026.

The project investigates sales performance, profitability, product performance, customer behaviour and customer satisfaction using Python, SQL Server and Power BI.

**Note:** CoffeeBites is a simulated business dataset created for learning and portfolio purposes. The findings represent the generated dataset, not a real company.

## Business Objectives
- Analyse monthly revenue and order trends.
- Evaluate gross profit and gross profit margin.
- Identify top-performing products.
- Understand customer purchasing behaviour.
- Analyse customer reviews and satisfaction.
- Identify possible reasons for declining business performance.

## Tools & Technologies
- Python – Pandas for data cleaning and preprocessing.
- SQL Server – Data analysis using T-SQL.
- Power BI – Interactive dashboards and visualisations.
- GitHub – Project documentation and version control.

## Project Workflow

### 1. Python – Data Cleaning
- Loaded CSV datasets using Pandas.
- Checked missing values and duplicate records.
- Standardised date and payment method formats.
- Checked product, customer and transaction references.
- Exported cleaned datasets.

### 2. SQL Server – Data Analysis
- Business KPI analysis.
- Monthly revenue and profitability analysis.
- Product performance analysis.
- Customer behaviour analysis.
- Customer review analysis.

### 3. Power BI – Dashboard Development
Created five report pages:
1. Executive Overview
2. Sales Performance Analysis
3. Product Analysis
4. Customer Analysis
5. Customer Reviews & Satisfaction

## Key Business Findings
- June recorded the highest monthly revenue.
- October recorded the lowest monthly revenue.
- Gross profit was highest in June and lowest in October.
- Gross profit margin declined during the final three months.
- Mocha generated the highest total revenue and gross profit.
- 8 AM recorded the highest order activity and revenue.
- Long-wait feedback was a frequently mentioned customer comment.

## Business Recommendations
- Investigate the reasons for declining customer visits and orders.
- Review ingredient purchasing costs and pricing strategies.
- Improve morning service efficiency.
- Monitor customer feedback and satisfaction.
- Focus on maintaining the performance of high-contributing products.
